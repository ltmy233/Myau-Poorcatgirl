# Poorcatgirl（可怜猫娘）

Minecraft 1.8.9 Forge 客户端。
jar 体积这么大是因为塞了主界面的动态背景mp4（1080P 60FPS）

## 构建

```bash
./gradlew build
```

输出 `build/libs/Poorcatgirl V2.5.jar`
